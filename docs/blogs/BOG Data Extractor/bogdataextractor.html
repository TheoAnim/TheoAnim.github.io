Recently, Ghana’s GoldBod released a report of its trade with the Bank of Ghana. The report is a pdf document. Researchers interested in the data will have to find a way to extract the data. To solve that problem, we developed a Shiny web application specifically tailed for this report. Users simply upload the PDF and in return gets clean CSV ready to download.
